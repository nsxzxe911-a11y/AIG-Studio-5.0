AIG-II × AIG Studio 5.0 · 雙專案正式入口

低階 Web 工作區已撤下

依使用者要求，原先另外製作的 Web 版 CNC 工作區已停止提供，不再把這些畫面當成原本的 Android／Windows 主程式。

保留原生程式與使用者資料

本次處置只針對網站的低階工作區，不刪除雙專案 Android／Windows 原始碼、GitHub 建置紀錄或核准素材。不執行 localStorage 清除，也不移除 CAD／CAM／NC 工作副本。

目前尚未完成最新原生版本的 Web 整合驗收，因此不提供假的加工畫面、模型或下載按鈕。

原生版本與正式進度

AIG-II 和 AIG Studio 5.0 的 APK、EXE 必須以實際建置產物、版本及 SHA 驗證。舊 GitHub Release 不能冒充最新 Android／Windows 版本。
