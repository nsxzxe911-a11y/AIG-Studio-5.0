低階 Web 工作區已撤除

依專案要求，已停止將後續 V90～V95 Web Runtime 當作正式 CNC 工作程式。原本 Android／Windows 的程式不受此頁影響；目前不以 Web 版號取代原生 APK／EXE 的較高版本。

沒有自動刪除你的 CAD、CAM、NC 或 G-code 資料。舊網站存放在相同網域瀏覽器的資料仍保持原狀，但低階 Web 操作介面已停用。
