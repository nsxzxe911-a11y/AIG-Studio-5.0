# AIG FastModel 4.6｜自研跨姿勢比例對齊＋頭頸馬尾三塊真網格（技術 Draft）

## 本次實際接通

- 來源仍是 AIG Library `/AIG/Asset Packs/FastModel-4.5-Heroine-WhiteSwimwear-4Poses-DRAFT/` 的四張 1122×1402 原始 PNG；`aig-calibration-4-5.mjs` 的精確 SHA 與人工標點是唯一合法輸入，不上傳別人的照片、不替換原圖。
- `aig-head-neck-4-6.mjs` 將已接受的 1～4 張校正結果轉成統一**表觀身高比例**的 2D 座標系，測量每張頭部高度、肩寬、髖寬並比較中位數。相差過大時 `AIG46_POSE_CAMERA_SCALE_OUTLIER_REVIEW`，不平均錯誤透視或假裝能從正面照算出背面。
- `buildHeadNeckPonytail()` 生成三件**實際立體、封閉、有完整三角面索引**的個別模型：橢球頭部、封口管狀頸部、可調左右位置／向後厚度的彎曲馬尾。3D 數值是原始 2D 比例作起點＋自研幾何假設，**不是**自動重建真臉、真髮絲、真頭頸皮膚或從單張照片取得深度。
- `meshTopology()` 檢查索引、退化三角面、拓樸每一條邊正好被兩面共用、三角面相反方向配對、正向有號體積；任一不過就 BLOCK。三塊模型**分離且未焊接**，代理碰到不代表真實接合／蒙皮通過。
- `index.html` / `app.mjs` 4.6 真 RGB 工作區：1～4 張已核對的 4.5 人工標點 →「生成 3D 草模」→ 真三角面旋轉視圖 0° 到 315° → 馬尾左右／向後距離即改局部部位 → 明確下載 `.obj` 和來源 QA `.json`。**OBJ 為真頂點與面資料，但不是正式 GLB／已有動畫骨架。**
- 4.0 真 GLB、4.1 SDF 預覽、4.2 免卡頓 GPU 計時、4.3 四肢部位快取、4.4 頭頸髮量風險檢查與 4.5 來源圖片校正全部保留。

## Zero Credits / Safety / No-Regression

- AIG 自研純 JS 幾何算法，沒有付費 AI inference、外部重建服務、第三方 API 或模型權重下載。
- 來源按完整 `sha256` 驗證，另輸出明確 `releaseAllowed:false`，未知區域標記推估；不會變更原圖、覆蓋主工作區或 4.0 GLB。
- 人體站姿／相機角度不明、肩寬差距大或錯誤標點，須退回 4.5 手動改正，不能偷偷以鏡像或猜測通過。
- 單元測試覆蓋四張 SHA、2D 正規化、中位數離群、頭頸髮尾三網格面／有向封閉／正體積、馬尾局部變化、OBJ 真面與按鈕回呼；Github Source Gate 成功也仍**不是**正式女主角、真機 FPS 或 Render 網站部署。
