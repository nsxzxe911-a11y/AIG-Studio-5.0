# AIG School3D Phase 17｜核准原圖高還原「可見輪廓／髮際線」工程

**最後可信前置**：Phase16 commit `68bd741ea2466d9f188909d5e62c6e34595c8613`，PR #12 僅獨立 Draft，不合併正式網站。

## 真正完成

- 自主研發 `tools/build_source_fidelity.py`，直接讀**已完成的 Phase16 GLB**，不從零生成另一個人偶。
- 88 條髮流以核准來源圖的局部髮色／可見髮區追蹤；修正折線的連續性與 V 形生硬散開，**現有 528 個真正三維細髮束網格保留**、重新定位而非加量。來源最小化位移的髮色覆蓋 proxy 從 **27.392% → 34.270%**，差 6.878 個百分點。這不是 3D 還原率，也不是語意分割 IoU，仍不算高品質外觀。
- 用 4 個**人工校正可見輪廓**，建立原圖 UV 貼圖的頭皮、瀏海、左右髮區；附獨立的 RGB 髮色判別 + RGBA 邊緣軟遮罩、手工臉部排除區。讓額頭、臉頰、眼睛原本的圖像不被髮絲顏色遮住。
- 528 髮片的 `COLOR_0` alpha 頂點屬性來自**原圖髮色遮罩**，GLB 內嵌 `625×590 RGBA PNG`，保留既有 `JOINTS_0/WEIGHTS_0`、176 髮束動畫通道，4 段原始動畫、原 18 組人物網格的頂點／骨架／權重（其中舊頭髮網格更換透明貼圖材質）及原始二進位前綴，不改人臉/身體的大小。
- 完整輸出 `phase17-source-guided-NOT-APPROVED.glb` 共 **111 mesh**（原 18 + 88 髮束 bundles + 4 髮片包覆 + 1 頸部 UV 補面）／528 髮束 primitives／原 176 髮束骨節和權重。
- 16 項本地**核准來源**測試 PASS，16 項**純合成來源**測試 PASS；SHA、臉部排除、RGBA 來源、GLB 權重、可逆編譯、不可自我授權等測試未跳過。

## 原圖與 GLB 對照注意事項

`out/phase17-source-mesh-audit.jpg` 右側是**由輸出 GLB 中原本的 UV 影像網格加上新增貼片投影**，再顯示來源相符的細髮束，是「技術正面投影」而非真實 3D PBR 旋轉渲染。此階保留了原圖像素，因此正面看起來比較像原圖；**不代表建構出同樣精細的三維臉部、背面、頭髮層次**。目前頭髮仍有部分人工邊界與髮束流向誤差。
