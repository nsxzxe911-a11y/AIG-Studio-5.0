# AIG 6AX 正式機構規格 V1
**文件 ID：** AIG-6AX-MECHANISM-V1  
**建立日期：** 2026-10-19  
**範圍：** AIG-II / AIG Studio 5.0，Web V66 優先，後續 Windows / Android  
**狀態：** 使用者確認設計意圖；機構／模擬／CNC Safety Gate 尚未 PASS。  
**來源：** 使用者核准的雙側支承搖籃＋圓盤工作台圖片及 Z 軸主軸頭 45° 傾斜要求。此圖僅為外觀參考，不是已驗證 CAD 組立或製造圖。  

## 1. 設計定案
- **不要擁擠的外殼。** 保留左右支承、搖籃、圓盤、XYZ 滑軌、主軸及足夠加工活動空間。面板上可以有 RGB 光效，但不能用外殼遮蔽機構。
- **工作台第一旋轉自由度 A（翻轉）：** 左右同軸支承共同驅動*同一座*搖籃，目標連續上下翻轉 360°。左右兩端不能錯誤算成兩個獨立軸。
- **工作台第二旋轉自由度 B（圓盤）：** 搖籃內圓盤相對搖籃旋轉，目標連續 360°，可在搖籃任意合格姿態下獨立轉動。
- **主軸頭第三旋轉自由度 H（頭部傾斜）：** Z 直線軸帶動的主軸頭再設一個**真實轉軸**，刀具方向可由垂直姿態偏轉到 45°，可保持傾角進給切削。H 為機構 ID；於 AIG UI 可暫示為 `C/H-HEAD`，實際 Fanuc 字母必須依機台定義與 Post 映射，不可直接把「Z」當成旋轉軸。
- **XYZ：** X/Y/Z 是三個彼此獨立的直線軸，Z 本身仍是直線位移，不因主軸頭能傾斜而變成旋轉軸。
- **合計 6 自由度：** X、Y、Z、A、B、H 各有**獨立**位置或姿態控制能力，才是本案的六軸機構。只有固定 45° 刀頭、或兩個支承重複控制同一轉軸，都不構成新增自由度。

## 2. 座標、軸命名與極限
| 邏輯 ID | 部件與實際運動 | 設計行程／範圍 | 註記 |
|---|---|---|---|
| X | 主軸／滑台左右直線位移 | 由實體機台模型決定 | mm；不得預設虛構機台行程 |
| Y | 主軸／滑台前後直線位移 | 由實體機台模型決定 | mm |
| Z | 垂直主軸升降 | 由實體機台模型決定 | mm；獨立於 H |
| A | 左右支承同步的搖籃翻轉 | 目標 0–360° 連續 | 「上下 360°」，須核實驅動、線纜及限位 |
| B | 搖籃中間圓盤的獨立回轉 | 目標 0–360° 連續 | 「橫向 360°」，相對搖籃座標轉動 |
| H (UI 暫稱 C/H) | Z 滑台末端的主軸頭鉸接傾斜 | 最少可達垂直 0° 至指定 45° | 方向、正負行程、限位待機台定義 |

本案的 A/B/H 是**產品邏輯與機構名稱**，不是可直接上真機的 G-code 軸字母承諾。一般 CNC 軸字母的旋轉幾何依 X/Y/Z 軸向定義；輸出 NC 時應讀取 MachineProfile 映射 `{A,B,H} -> controller axis words`，並經過 TCP、刀長、旋轉中心、限位、機台專屬 Post 驗證。未設定時 **BLOCK MACHINE OUTPUT**。

## 3. 必須正確的運動階層
```
MACHINE_ROOT
├─ FRAME / BASE / LEFT_SUPPORT / RIGHT_SUPPORT
├─ LINEAR_X
│  └─ LINEAR_Y
│     └─ LINEAR_Z
│        └─ HEAD_TILT_H (pivot + joint limits)
│           └─ SPINDLE
│              └─ TOOL_HOLDER
│                 └─ TOOL
└─ TRUNNION_A (左右支承共用一條旋轉軸線)
   └─ CRADLE
      └─ PLATTER_B (圓盤中心獨立旋轉)
         └─ CHUCK / FIXTURE
            └─ WORKPIECE (可隨時更換)
```
- 對應真實機構建模時，X/Y/Z 的親子順序以量測後的實際機台為準；不可為方便程式而錯配。
- 每個旋轉關節必須有真實的 `pivot`、單位軸向量、零點、正負方向、角度限制、驅動節點。
- 須以完整剛體轉換矩陣計算工作台與刀具之相對位姿：`T_tool = T_xyz · T_headH · T_spindle · T_toolLength`、`T_workpiece = T_cradleA · T_platterB · T_fixture · T_part`；不得只更新 HUD 數字或假動畫。
- 不能把左、右支承各列成獨立轉軸；它們共同構成一條 A 旋轉軸。

## 4. 活動空間與避讓
- 最低視覺要求：搖籃在 A = 0/90/180/270/360°、圓盤 B = 0/90/180/270/360°、頭部 H = 0/22.5/45° 時，都能清楚看見工件與刀具，不被外殼或面板遮住。
- 真實行程及空間以 `MachineProfile` 的幾何尺寸、關節限位、刀具長度、夾治具、線纜包絡及安全距離為準。設計目標「360°」不代表實體無限連續轉動獲得驗證。
- 須執行刀具/主軸/滑台/左右支承/搖籃/圓盤/夾具/工件之**連續路徑取樣**與掃掠包絡碰撞，不可只看起點終點。
- H = 45° 時重算 TCP 與刀具全長掃掠包絡；有碰撞、超界、未校驗旋轉中心或不確定之真機模型，必須 fail-closed。
- SIM/NC 播放不得自動捲動整頁；動畫畫面與 NC 焦點分離。

## 5. 模型資產規格
- 3D 格式首選 `GLB/glTF 2.0`；每一部件獨立 Mesh/Node；材質 PBR，RGB 光效只作外觀，不改安全幾何。
- 核心部件：`FRAME`, `X`, `Y`, `Z`, `TRUNNION_A`, `PLATTER_B`, `HEAD_TILT_H`, `SPINDLE`, `CHUCK`；`TOOL` 與 `WORKPIECE` 必須另外載入，不可烙在機台模型。
- 輕量模型供手機首載；高精細版本延後載入。模型不得在網站起始頁與其他 10 頁一起強迫下載。
- 材料移除由獨立的 CAM/SIM 資料模型管理，視覺網格不取代 0.001 mm 座標／材料移除數值證據。
- 圖片作為 UI 造型與比例 Authority；**不直接作為機構尺寸或運動正確性 Authority**。

## 6. Web UI / Callback
- 主頁：`6AX / MACHINE`；副頁：`NC_FIRST`, `AXIS`, `HEAD_TILT`, `CAMERA`, `COLLISION`, `TOOL`, `FIXTURE`。
- 桌面：大加工視窗目標 70–75%；NC 與控制側欄約 25–30%。
- Android：獨立「畫面／控制／程式」分頁；切換時保留相機、刀具、NC 編輯、軸態、播放進度。
- 控制命令：`AXIS_A_SET`, `AXIS_B_SET`, `HEAD_H_SET`, `XYZ_JOG`, `SIM_PLAY`, `SIM_PAUSE`, `SIM_SINGLE_BLOCK`, `SIM_DRY_RUN`, `RESET_VIEW` 等必須綁定真 Shared Command / State；不可只改文字。
- 位置 HUD：`X/Y/Z` (mm)、`A/B/H` (deg)，並明確區分邏輯 H、實際 NC 軸字母及機台連接狀態。
- C/H 傾斜視圖包含：垂直 0°、實際角度、45°、旋轉中心、刀尖 TCP 與 Clearance。
- 任何對真機輸出的 RUN／POST 皆需機台專屬 Verify Gate；未通過僅可進入模擬／教學模式。

## 7. 測試與驗收案例
| ID | 項目 | 操作 | 必須取得的證據 |
|---|---|---|---|
| AX6-01 | XYZ | X/Y/Z 各自正負位移 | Mesh 位置及 HUD 一致、單位正確 |
| AX6-02 | A 360° | 0→90→180→270→360° | 整座搖籃轉動，兩側支承同步，同一 pivot |
| AX6-03 | B 360° | 0→90→180→270→360° | 只有圓盤/夾具/工件相對搖籃轉動 |
| AX6-04 | H 45° | 0→22.5→45→22.5→0° | 頭部真關節傾斜，Z 直線滑台不被當作旋轉 |
| AX6-05 | 姿態聯動 | A=90°, B=180°, H=45° | 刀尖/工件轉換矩陣與動畫/HUD 同步 |
| AX6-06 | 邊界空間 | A/B 全週 + H=45° + 最長核准刀具 | 包絡、行程、夾具、支承及線纜安全檢查 |
| AX6-07 | 干涉測試 | 刀具接近搖籃/圓盤/工件 | 連續掃掠碰撞證據，危險輸出 BLOCK |
| AX6-08 | 換件 | 空台→方料→其他 CAD 工件→空台 | 工件獨立載入／移除，不更改機台 node |
| AX6-09 | NC-first | 開啟 6AX NC 編輯並切回機台 | 編輯內容保留；位置、動畫與材料移除一致 |
| AX6-10 | 跨裝置 | Chrome Windows / Android 窄屏 | 大視窗、手機三分頁、無橫向擠壓 |
| AX6-11 | 失敗保護 | 缺 MachineProfile、Post 或 TCP | Machine output FAIL CLOSED；其他頁繼續使用 |
| AX6-12 | 精度 | 0.001 mm 座標鏈與材料移除測例 | 數值誤差／體積證據，不以圖片代替 |

驗收順序：模型節點存在 → 各軸單獨運動 → 聯動姿態 → 動態碰撞/行程 → NC/SIM/材料移除 → 手機/桌面實測 → 雙專案 exact SHA / Render Gate。任何真機安全案例未完成，不可標為 `6AX CNC SAFETY PASS`。

## 8. V1 收口與版本狀態
- **已定案：** 工作台外形參考、雙側支承搖籃、A 整體翻轉 360° 目標、B 中央圓盤 360° 目標、主軸頭由 Z 滑台延伸真鉸接可到 45°、保留足夠空間、無大型外殼、工件獨立。
- **仍待實作與實測：** 6 個真可控自由度、機台真實行程與安全包絡、旋轉角度限制、TCP/IK/Fanuc Post、連續碰撞、材料移除精度、GLB 與實際 Render UI 整合、Windows/Android 實機畫面。
- **禁止誤報：** 本文件是機構／Web Runtime 的**正式施工 Authority 規格**，不是已完成模型、真 6AX 量測或 CNC Safety Gate PASS；不得從文字或概念圖自動升為功能驗收通過。
