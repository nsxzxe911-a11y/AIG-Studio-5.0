V41｜3AX～6AX 正式加工工作區重新排版

已根據使用者確認 V40 不再跳頁後，把問題轉向真正的工作區排版。雙專案四軸頁同步接入可操作的「機台優先／均衡／程式優先」版型，桌面可調加工與 NC 編輯比例，編輯面板獨立捲動；手機保留 3D 加工全寬單欄，程式優先則調整工作頁前後順序。真 WebGL 視窗、刀具、CAD/CAM、NC-first、V40 無自動捲動及材料移除均保留；版型按鈕只改 CSS，不執行 CNC 指令。

AIG-II 5AX ↗　Studio 6AX ↗

V40｜修復 G-code 執行仍自動拖動網頁

使用者實際截圖顯示 V39 播放時主畫面仍向下捲。V40 直接修 AIG-II 與 Studio 四軸 Runtime：G-code 清單每次執行換行不再清空重建、不再自動捲動；只在原程式行更新正在執行、已完成、警報及碰撞狀態。手動跳至程式行仍可定位清單。當前加工頁的瀏覽器 scroll anchoring 已停用，3D 模型、切削及 NC 核心保持原樣。

AIG-II 五軸 ↗　Studio 六軸 ↗

V39｜自動模擬切削時不再跟隨 G-code 跳頁

雙案 3AX～6AX 播放核心 renderExec 原本在每次區塊切換時呼叫 scrollIntoView，可能把整個網頁拉到 NC 程式。現在僅於內部 G-code 執行清單捲動與高亮；加工視窗保持使用者目前的觀看位置。手動定位程式行改為 preventScroll，保留原真 3D 模擬、材料移除與所有 NC 控制。

AIG-II 五軸 ↗　Studio 六軸 ↗

V38｜右上角手機版切換鍵正式接通

由手機／桌面切換截圖發現右上角仍選在「自動」，桌面寬度自然顯示雙欄。V38 調整 AIG-II 原切換事件，讓按下「手機版」立即同步實際 3AX～6AX 版型狀態；同時把相同的真實控制加入 Studio 工作區。手機版在桌面預覽以 480px 寬度顯示原 WebGL 工作區，十頁導覽橫向可滑，加工／G-code 上下排列，保留 NC-first 和 WebGL 切削。切換功能不修改工作檔或機台狀態。

AIG-II 五軸 ↗　Studio 六軸 ↗

V37｜依實際加工工作區寬度修正手機雙欄擠壓

使用者截圖證實 V36 在桌面瀏覽器的手機模式或窄容器下，仍把加工狀態與 NC 編輯器塞入雙欄。V37 改以實際工作區寬度與已選手機版模式判定，3AX／4AX／5AX／6AX 的機台視窗、NC 程式與完整數據上下排列。導航維持水平可滑，安全警告仍會展開。保留 V35 WebGL 實際機台幾何、V33 切削核心與既有檔案。

AIG-II 五軸 ↗　Studio 六軸 ↗

V36｜手機版排版壓縮與重疊修復

在正式 AIG-II 與 Studio 兩工作頁修正頂部 Grid 自動隱含欄位、十頁導航擠壓、3～6 軸雙欄溢出和統計卡先於加工畫面的問題。真 3D 加工視窗保留在上方，十頁可橫向滑動，NC、CAM、CAD 與加工欄位自適應單欄；冗長 HUD 資訊可展開，碰撞異常會自動展開警示。未覆蓋 G-code、回復舊模型或改動 CNC 核心。

AIG-II 手機三軸 ↗　Studio 手機六軸 ↗

V35｜3AX～6AX 實際 WebGL 機台模組修復

修正 Studio 四軸頁共用簡化底座的問題，直接將四套獨立機台幾何接入原本 WebGL 加工渲染：3AX 立式虎鉗、4AX 臥式卡盤、5AX 雙側搖籃、6AX 直立單臂 A/B/C 搖籃。AIG-II 的既有機台結構同步加入實際 3D 細節。資訊 HUD 移到加工視窗下方，手機開頁先看見機台而非一長排統計資料。仍保留原 G-code 驅動、切削網格及安全提示；這些程序模型不是已核准 GLB 原廠數位分身。

AIG-II 3AX ↗　Studio 6AX ↗

V34｜AIG-II 與 Studio 5.0 共用 Web 發佈版本

兩套現有 Web 工作頁載入同一個 dual-web-v34.js，將 Web 版本統一為 34.0.0，並提供可操作的十頁原始導航檢查、跨工作區切換與 SHA 核對；保留 V33 真 3D 工件網格效能優化與 V32 FPS 面板。Android／Windows 原生版號（432／375）及各自的 GitHub SHA 未被修改；本機 NC、CAD、CAM 存檔保持隔離。

V28｜真控制快捷與狀態修正
