# Real3D｜真 3D 五指立體分支驗證 Gate V1

日期 2026-10-24。基於 Draft PR #67 的高密度原始 Index 五區檢查，PR #68 增加對五指**真立體分支**的技術診斷。正式 RGB、CNC 雙案及原 Render / APK / EXE 不更新。

## 解決的真實缺口

21＋6 個原始三維標記都準確貼在網格上，也可能只是五個不同的位置、同一塊平板、同一個柱體，絕不等於真的五根手指。因此不能把五個指尖標記或正面像素當作真五指。新獨立 read-only 模組使用 PR #67 保留的 OBJ 原始 GLOBAL XYZ／Uint32 Indexed faces；**不從 GPU chunks 做拓樸**，避免把分塊接縫當人體破口或分叉。

每側腕部和 5 個指尖必須有來源原始座標，掃到原始三角面表面，檢查五尖彼此不同且落在手腕同一個原始索引連通殼；依手腕到五尖平均方向建立四個 distal 平面，在局部原網格半空間求原始 Indexed surface components。只有在至少一個切面下，五個尖端分別落在五個不同的原始曲面連通分支，且每個分支有足夠來源頂點，才顯示 technicalFiveDistalBranchesObserved=true。錯誤標記、脫落外殼、平板、未分叉厚塊都要 BLOCK。結果輸出切面位置、三維來源頂點、區域原始 triangle 數、五指 component 數及來源 SHA。無自動補面、減面、細分、假手指、模型修改。

## 限制與 Gate

- 這是**平面切割的局部拓樸診斷**，嚴重彎曲手指、拇指展開、閉合拳頭、厚手套或手部遮擋會造成未能觀察到五個獨立末端，須人工核對；單一切面分離是技術觀察，仍不保證自然人體。
- 實際五指骨節、關節、指甲、皮膚、自然比例，均需獨立真人來源和專業視覺複核。
- 不因正面照片五尖看似分離就假定真立體，無法確認需維持 BLOCK，不拿程序式人體通過。
- 本機 source sha / markers 與只讀 local report，不上傳第三方。
- Node fixture 為明確 NONHUMAN 工業五叉一體實心結構（正案例）、一塊連續平板帶五個不同指尖標籤（反例）、從腕部分離的五塊桿件（反例）、缺標記/偽造 SHA/破壞三角面（反例）。所有例子 releasePASS=false。
- Chromium 延續 PR #67 的非人體高密度 113,400 頂點／226,080 三角面真 GPU 回歸，新增驗證五指分支資料確實來自原來源並在缺標記時維持 BLOCK。
