# AIG CNC / AIG Studio 資產工程規則

這份規則用繁體中文定義，不再用模糊的「鎖住、不可變、禁止修改」英文描述工程素材。

1. 官方核准原始資產只保留原檔與來源血統，不得覆蓋或刪除。
2. 上述保留規則不代表工程介面不能修改。
3. 工程 UI、圖片、RGB 按鈕、動畫、Theme、桌布、排版與派生資產都可新增、修改、替換。
4. 工程版本可以直接為完成產品而重做視覺與圖片，不必保持舊版外觀。
5. 新素材必須保留來源、版本與完整性資料；要升正式版時再通過 Runtime、完整性、來源血統與 Release Gate。
6. 安全、CNC 執行、座標、完整性與防竄改 Gate 不因本規則而取消。
7. 不得把「官方原始基準保留」解讀成「工程圖檔不得修改」。
8. 版本只往上；驗證失敗的候選不升正式主線。
