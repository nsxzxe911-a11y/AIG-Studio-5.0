# Real3D 人體渲染規格 V1｜正式入庫版

**定案日期**：2026-10-24  
**Authority ID**：`AUTH.REAL3D.HUMAN.BROWN_RENDER.V1`  
**決策**：先執行 AI 建議的標準階段。使用者建議的「黑線後再多次細緻渲染漸層凹凸、隙縫、立體深度」保留為後續加強階段，**不混入 V1 源碼而假稱已完成**。  
**機器可讀合約**：`formal-web/shared-3d/authority/aig-real3d-human-brown-render-v1.json`。

## 一、渲染對象與顏色定版

- 人體必須是**來源真三維的 OBJ/GLB 原始 XYZ 網格**，可追溯來源授權、檔案 SHA-256、尺寸與朝上座標。沒有可信人體資料時，只能做「渲染管線測試」，不能稱真人或照片 1:1 驗收。
- 人體檢查模式固定為**咖啡色系**：主色 `#946B4C`、深部 `#583C2E`、中間過渡 `#A97D5A`、局部亮部 `#C89A74`。最終具體材質仍須依來源外觀人工核准；這些色值只是 V1 的可重現中性色參考，**不代表所有人的真實膚色**。
- 外邊線 `#17110E`（近黑），建議在 1080p 以 **2 px** 起測（容許 1–3px 作解析度縮放），背景 `#C4BEB3`（不與黑色線混為一片）。
- **不使用白色人體為正式主體**；**不使用 RGB 幻彩作人體主色**。RGB Glass 僅屬 UI；星門/飛船可以在人體確認後使用獨立特效層。
- 不可由灰模、網格線框、三角面增加、平滑、SDF/Metaball/Template Morph 冒充自然人體完成。

## 二、AI 建議的標準 RenderGraph（先施工）

| 次序 | Pass / Gate ID | 輸入與輸出 | 正式要求 |
|---|---|---|---|
| 0 | `REAL3D.GATE.GEOMETRY` | 原始 GLB/OBJ → 來源比例/座標報告 | 固定來源 SHA、實測身高、正交前/側/背/斜相機；不可調改人體頂點 |
| 1 | `REAL3D.PASS.OUTLINE` | 真模型投影 → **一條黑色外輪廓** | 畫的是 3D 物體剪影的**外邊界**，不是內部三角線、骨架線；要有足夠對比 |
| 2 | `REAL3D.PASS.BROWN_BASE` | 同一模型 → 不發光咖啡色實體 | 填滿整體表面，不是網狀；使用 Alpha 1，不靠光線判定厚度 |
| 3 | `REAL3D.PASS.VOLUME_SHADOW` | 法線/單向主光/柔和補光 → 大面積漸層 | 表現頭、頸、軀幹、四肢大體積；粗糙度建議 0.72–1；只影響像素，不改 XYZ |
| 4 | `REAL3D.PASS.HIGHLIGHT` | 結構明暗 → 微弱高光 | 光澤避免塑膠娃娃感；高光亮度有上限、無發光外緣 |
| 5 | `REAL3D.GATE.VISUAL_HUMAN` | 四視角與可信來源 → 外型核准 | 頭臉五官、頭頸接合、肩腰臀、五指、膝踝、腳掌/趾、側面厚度需人工驗收 |
| 6 | `REAL3D.PASS.SCENE_FX` | **僅人體外觀合格後** → 電影特效 | 另加星門、星艦引擎與環境光；禁用人體邊界 Glow 作輪廓驗收 |

### 執行原則

- Pass 0–5 的影像必須沿用同一套 XYZ、SHA、相機、縮放、姿勢、輸出尺寸，禁止偷偷調變身材。
- 黑色外輪廓應由**深度/物件遮罩的螢幕空間外邊界**產生；不能將白色整個模型冒充黑色外輪廓。
- V1 大陰影依真來源曲面法線生成；若缺乏鼻子、五指或腳趾等幾何，不得在陰影中偽造立體結構。
- 光影用於呈現而非修補外型。真正的 Bloom 會擴張發光像素的可視輪廓，**不會改變來源三維頂點**。
- 人物表面、服裝厚度、體型來源須分別記錄；穿戴物不能當成肌肉或脂肪。
- 手機、Windows 畫面共用渲染 Command 合約，但保留核准的 RGB Glass Mobile/Desktop 分版與功能操作；不更換正式首頁。

## 三、使用者後補方案（保留，但暫不搶先）

保留 `REAL3D.FOLLOWUP.MULTIPASS_GRADIENT_CAVITY`，待標準版輪廓、咖啡底、大陰影、高光分別完成並通過來源外觀檢查後，再增加：

1. 微凹處漸層（Micro Cavity）：局部表面縫隙或接合結構的微陰影；
2. 解剖轉折陰影（Crease Shadow）：例如鎖骨、腋下、膝、指縫（**以真的來源幾何支撐**）；
3. 區域遮蔽（Local Occlusion）：人體與衣服接觸或肢體遮擋處；
4. 材質細膩漸層（Material Microgradient）：輕微膚面粗糙度及光照變化。

後補多階段是**畫面呈現**技術，不是重建缺失的手指或面部幾何。

## 五、施工邊界

- 用這份 V1 合約當新施工的穩定目標；修改影像特效不准改 `aPosition`、`uModel`、原始頂點或 CNC Core。
- 不回退 AIG-II／AIG Studio 5.0／FastModel 已完成核心；不替換正式 RGB HOME、NC 或 3AX～6AX。
- PR 繼續 Draft，Gate 未全過不 merge、不部署正式 Render、不宣稱 Android APK 或 Windows EXE 已產出。
- **規格已經核准、寫入倉庫 ≠ 人體最終渲染成功**；程式完工與真畫面驗證必須另外提供 SHA、截圖與原始模型的對照。
