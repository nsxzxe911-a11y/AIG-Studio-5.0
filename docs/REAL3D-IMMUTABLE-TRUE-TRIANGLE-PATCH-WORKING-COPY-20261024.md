# Real3D 真來源小破洞修補工作副本 V1（2026-10-24）

## 不再只檢查：已開始真正修改 **工作副本的三角面**

接續 PR #61 真 OBJ／GLB 分腿截面 Gate，新增 `aig-real3d-local-hole-working-copy.mjs`。此演算法只有在使用者在本機工作區按下「建立真正三角面修補工作副本」時才執行，來源為已載入、具實測高度與來源 SHA 的**原始 OBJ**，不以照片或陰影推估被遮蔽的幾何。

- 真分析全部來源 Indexed XYZ 面片的边缘使用次數、相鄰面方向，找出只有一張三角面使用的原生開放邊。
- 僅接受不分叉的獨立閉合小缺口（每個 3～8 條邊、最多兩個缺口，直徑上限 100 mm、近乎共平面偏差不超過 0.5 mm、凸形、三角面面積至少 1 mm²）。
- 用**現有頂點索引**建立反向邊界 winding 的實際三角面 `f ...`。本版不新增任何頂點，不改原始座標、不重排或修改既有面片。只在新獨立 OBJ 末尾附加新面及 SHA 來源註記。
- 重新呼叫原有真 OBJ importer，檢查補面候選 openEdges=0、nonManifoldEdges=0、退化三角面=0；不安全時直接 BLOCK，不生成工作副本。
- 新工作副本獨立 SHA、可下載真 OBJ；瀏覽器同時在原來「修復前後兩份 OBJ GPU 比對」載入新工作副本，沿用四視角咖啡色真 GPU 截圖、差異 JSON、來源 SHA。
- 只修補這種**可由原始周圍真邊界界定**的小三角孔：大範圍臉部缺失、真正手指、頭頸曲面、單張照片推估背面等沒有足夠來源證據，不能憑空補形；這些都不自動修復。
- 如果來源本來就沒有破洞，必須 BLOCK：不產假新檔。任何壞 winding、非流形、大洞、分叉、非平面／凹形洞也 BLOCK。
- 即使補面後拓樸完好，合成非人體橢圓仍然保留原來約 839 mm 正面寬、504 mm 厚、單一實體下肢截面，**外觀 BLOCK 絕對不因此改為 PASS**。
