# Real3D｜下一核心：來源原生手指關節與手掌接縫量測 V1

2026-10-24。基於 PR #68 真五指末端分叉 Gate 繼續向前。此版本是靜態三維來源**診斷器**，不是把程序五叉器官稱為真人手部、不是動態骨骼，也不是已完成皮膚變形。

## 已接上的新功能

高密度原始 OBJ 匯入 → 5 區來源三角面與 27 點檢查 → 真五指末端連通分叉 Gate → 新的 finger-junction Gate → 四視角真 GPU。新增程式獨立讀取 PR #66 匯入器保留、PR #67 五區驗證用的**原始全域** Indexed XYZ，絕不讀取 52k GPU chunks 局部 indices 來誤報裂縫。

額外**可選**本機三維來源標記：左右各五指，每指 `Base` 與 `Middle` 共 20 點，例如 `leftIndexBase`、`leftIndexMiddle`；既有 `leftIndexTip` 已保留。標記不完整必須 BLOCK，不能自動根據影像或資料填假座標。原本 27 點，加上 20 點後，一組完整來源可提供 47 個觀測座標（不等於 47 個人體結構都驗真）。

每指從原始三維座標量測：
- 指根和中段鄰域的原始頂點數、三角面數、邊長 P95、三角面面積 P95；
- 真來源開放邊、非流形邊、繞向錯誤、退化三角面，避免不連續皮膚假成功；
- 相鄰三角面法線夾角 P95，只作來源 surface facet 折角診斷，不從 shading 偷取曲面；
- 三個標記的相對折角；如果標記看起來彎但原始三角面完全平坦，明確給警告；
- 五指前階段真末端分離若不成立，本階亦保持 review/block。

GUI 沿用原高密度五區＋四視角**真按鈕**，新增十指逐指量測表格及本機 SHA JSON，Render 首頁與 CNC 完全不變。手機/桌面未公開正式發版。來源所有原始 vertex、face 保持不變；不添面、不改形、不平滑、不 weld、不細分、不自動代替真人體來源。

## 評估界線

靜態三維物件不能從單張網格獨立證實「真正運動關節」、「彎曲後皮膚合理延展」或「真人五指自然外觀」。因此即使 20 個標記都吻合、局部拓樸沒有開放邊，也不能自動核准人體、1:1 真人照片、動畫骨骼或發版。高折角也可能是低密度、掃描雜訊、衣物或刻意姿態；報告提供複核資料，不自動修形。
