# Real3D｜高密度真 3D 五區解剖＋四視角 GPU 真來源比對 V1

2026-10-24 · 疊在 Draft PR #66 之上的獨立候選。未 merge、不部署 Render，不修改正式 RGB 首頁或 AIG CNC 雙專案。

## 真正修正
前版有超過 11 萬頂點的高密度來源讀取與 GPU 分塊，但既有五區分析工具受單一網格及 11 萬頂點容量限制。本階從高密度 importer 輸出原始全域 Indexed XYZ、原始向上軸及身高校正基準，局部診斷一律使用全域原始三角面，不將 GPU chunk 重複參照的邊界誤判為原始裂縫。

檢查區域是頭頸、左手五指、右手五指、左腳、右腳。資料包含原始三角面數、開放邊、非流形邊、方向衝突、局部三維尺寸、最長邊 P95、面積 P95、原始索引連通性及本機 JSON 標記對原始網格的貼合誤差。標記仍需 21 個既有座標，另外加上 leftMiddleTip、leftRingTip、leftPinkyTip、rightMiddleTip、rightRingTip、rightPinkyTip 六個指尖，合計 27 個。五指標記存在不證明有五個獨立手指的自然形狀。

工作區新增真按鈕，從同一份已匯入來源擷取 front、side、back、threeQuarter 各一張原生 1080×1920 GPU PNG，逐視角和使用者本機透明 PNG 進行輪廓 IoU 對照。來源／圖片 SHA 與原始頂點、三角面數可一起輸出 JSON。缺來源、標記或參考 PNG 就記錄 BLOCK；單純有四張 GPU 圖不代表四張參考照片驗證完成。

不添加人體模型、不細分、不減面、不平滑修補、不自動偽造指頭、背面或照片。未取得獨立授權可核驗真人掃描來源與四張同人參考圖前，人體來源真實性、五指自然度、真人外型、照片 1:1、動畫骨架、正式發布，一律維持 BLOCK；所有輸入留在本機。
