# FastModel Real3D V115｜兩視角曲面去重後的原始開放邊界與缺面 Gate

第三專案 AIG FastModel／Real3D，從 V114 PR #116 的真 GLB 去重副本向前推進。**這個模組不填洞、不焊接、不中途捏造人體／動物解剖，也不把來源接縫看成已完成完整密閉 3D。**

## 本輪實際增加
- `aig-real3d-v115-observed-boundary-atlas.mjs`：直接讀取 V112 未加工 GLB 與 V114 去重 GLB 工作副本，以實際 SHA-256 重新計算確認原始與副本確實不同，檢查原始 BIN 位元組是新 GLB 完整前綴；第一視角三角面全部不變、第二視角索引是舊索引的有序子序列，所有 POSITION/UV、材質與圖片不變。
- 檢查兩個來源面的邊使用計數：非流形（超過兩片面共用邊）、法向／winding 相反錯誤、零面積三角形、沒有任何面引用的原始頂點。分別輸出兩相機：三角面數、開放邊數、開放邊總長（mm）、去重後留下的孤立頂點。
- 辨識**去重後新暴露出來**的第二視角開放邊；必須用第一相機的原始毫米深度與 RGB，在每條新邊的兩端與中點查證是真實可觀測、位置與材質有來源的共享表面，未證實的長度要列入 BLOCK，不做假修補。
- 原始 PNG RGB、GLB SHA、XYZ/UV、原始 BIN 不可改寫；研究 PASS 代表新開放邊有來源支持，**不是**已經生成閉合人體，也不等同真實掃描儀具有 0.001mm 精度。
- V112/V113/V114 繁體中文工作區新增可調查證門檻、開放邊長度統計、紅綠邊界示意與完整輸出稽核；使用者選用 V114 去重時，V115 會在 GPU 載入與 GLB 下載之前強制檢驗。預設 V112 原始雙視角模式仍維持。
- 補 V114 GPU 接軌待驗證之 UV 切線處理後，再走 V115 Node/Chromium 測試。新流程需要真正 GPU pass 才能稱 V115 完成。

## Gate 與真偽邊界
1. Node 正常來源：對可重現合成平面深度測試，一次性原 GLB→V114 去重工作副本→V115 新開放邊幾何及來源深度 RGB 證據 PASS；有些原頂點無面引用並不等於新增假面。
2. 故意移除來源另一相機的有效深度、改色、篡改 GLB 位元組或 SHA，均須 BLOCK，不可美化為閉合人體。
3. Chromium：實際傳入兩組 PNG、深度 JSON，相機世界矩陣與共同觀測點，建立真 GLB；經 V113/V114/V115 完整 Gate 後，V99 載入，V107 A90/B120/75% 真 GPU 繪圖截圖；來源 SHA 及新副本 SHA 必須不同；重測來源色差和局部深度錯誤 BLOCK。V112 原模式同輪回歸。
4. **合成來源只驗證算式及程式路徑。** 沒有實際掃描多視角的深度/相機標定來源，就不能證明自然人物、頭髮、衣物、動物或未知背面形體 1:1。正式手機 60FPS、Windows／Android GPU、真 4K 也不在本 Gate 內。
5. 只改 FastModel 研究 Draft 分支，不更新唯一正式 Render LIVE，不改 AIG-II／AIG Studio CNC 或 Fanuc，不產生 APK/EXE。

下一核心將要求真獨立多視角深度來源的掃描品質證據，並進一步研究多相機可信表面的法向與材質連續性、非觀測邊界遮擋分類；不可為了畫出完整人體而用程序性模板取代真資料。
