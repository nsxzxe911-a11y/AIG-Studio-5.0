# AIG 6AX Open Machine V1｜無外殼工作區模型

- 基準：使用者提供的 AIG 幻彩六軸機台圖片與本次核准的「殼可以不用」。
- 目標：不顯示外部大型鈑金外殼，直接展示主軸、XYZ 滑台、A/B/C 旋轉工作台、葉輪、刀具與 RGB 質感。
- 製作品：`AIG_6AX_OPEN_MACHINE_V1.zip`（本次對話交付，含 GLB 與 manifest.json）。
- 模型狀態：原創程序化輕量 GLB，60 個獨立幾何節點；**不是**原照片的精確 CAD 逆向模型。
- 驗收：靜態幾何完成；實際 WebGL 操作、真 A/B/C 運動、碰撞、材料移除、0.001 mm 精度、Android/Windows 尚未驗收。
- 單位：原型場景單位，尚未校準為 mm。
- 施工規則：不可將單張影像當作真 3D 模型；保留原始 V65 主程式與控制，模型接線後才進一步替換；不得宣稱 CNC 安全 Gate 已通過。
- 此 branch 只記錄模型 Authority 與後續替換入口；**未部署 Render**。
