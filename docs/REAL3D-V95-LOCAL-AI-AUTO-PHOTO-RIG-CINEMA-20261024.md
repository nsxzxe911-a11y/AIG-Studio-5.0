# Real3D V95｜單張肩部照片自動 3D 候選 × 六關節骨架 × GPU 快取 × 電影分段

日期：2026-10-24。已施工原型，但不是正式 1:1 人物或 2:12:08 動畫電影驗收。僅隔離 Draft 分支，不動 Render RGB HOME、不寫入 CNC、Fanuc、APK、EXE。

## 核心研發

1. **本機肩膀照片**：可開啟本機 JPG/PNG/WebP，原始檔案以 SHA-256 鎖定，Canvas 讀 RGB 像素、不遠端上傳。V95 Photo Vision 使用實際膚色色域線索估算臉部範圍。這是有侷限的啟發式，**非訓練好的 AI 人臉辨識**。沒找到足夠證據即 BLOCK。
2. **AI Adapter 擴充點**：未來可以傳入帶來源的本機 ML Landmark 偵測結果；只有實際整合且獨立驗證的本地推論才能標為 ML。現階未載入 ONNX 或其他權重，不能假裝已實現深度 AI 人體掃描。
3. **自動推估身體 3D**：以已偵測的臉部影像線索和預估頭身比，建立包含頭、身體、骨盆、雙臂雙腿的真 XYZ Indexed Triangle 有體積候選，配六個真 3D 可活動關節，沿用 V92 工作副本的頂點變形。屬明示推估的 Proxy Candidate，**不是已核准照片 1:1 人體來源**，也不可替換 V94 已核准的原始幾何。
4. **女主角身份鎖定**：繼承 PR #94 原女主角身份禁則。單張新照片未經視覺相似度和授權來源確證時，只能標為 NEEDS_HEROINE_IDENTITY_REVIEW，不得自動更換已定版臉型和角色。即使輸入照片 bytes SHA 一致也不代表高精度 3D 臉部掃描通過。
5. **GPU 快取與效能**：來源 SHA 為主鍵的限額 LRU 工作成果快取，依實測每幀毫秒與來源面數決定調低細節／保持／放寬畫質。不能聲稱 GPU 加速倍數，且全包覆、半包覆都不停止不可見骨架的運動。
6. **真影片動作**：獨立繁中研究頁，肩部照片選檔、自動建模、真 GPU 正／側／背／斜四視角、1.5 秒六關節連續動畫、逐幀控制、原生 PNG、瀏覽器支援時真正 WebM 短片錄製。沒有編碼器則 BLOCK。2:12:08（7928 秒、24 FPS，共 190272 影格）建立每 16 秒共 496 段的計畫，尚未產出任何完整長片。
7. **原始來源不變**：動畫由 V92 Working Copy 更新真正頂點與法線，原始幾何的 indices 不因動畫改變；貼圖平移不算通過。
