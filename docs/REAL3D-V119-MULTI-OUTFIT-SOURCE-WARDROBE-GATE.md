# FastModel Real3D V119｜同一角色多套真來源衣服與五軸 GPU 換裝工作區

第三專案 FastModel／Real3D，自已驗證 V118 PR #120 向前研發。此階回應「能有多套衣服」：**能，2～12 套，每套可放 1～5 個有自己來源 PNG／GLB 的衣物圖層**，如制服（上衣、下身、外套）、便服（洋裝）、運動服、鞋及配件，並能同一角色切換、保存及在 A/B 五軸 GPU 檢查。**不是宣稱 AI 已自動從照片生成真衣服**。

## 真功能與來源
- `aig-real3d-v119-multi-wardrobe.mjs`：只接受 V99 已實際解析且來源 PNG/GLB SHA 審核過的真三角網格。角色原 GLB 在不同套裝之間完全一致；衣物每一層必須另有來源 SHA、真 3D triangle mesh 與材質。嚴禁角色檔充當衣物、重複檔冒充不同服裝，或只換貼圖便稱已有不同服裝版型。
- 多套裝具獨立 ID 與繁中名稱；同一套可用 top / bottom / outerwear / dress / shoes / headwear / accessory 等真正衣物 slot，不允許同一 slot 重複。只顯示選中的一套，未選套裝不送 GPU；角色與衣物原始 GLB 不改寫。由原 GLB mesh 位置/法線/索引計算幾何 SHA，辨認不同裁切版型，並驗證衣物與角色原坐標框有基本空間重疊；錯誤來源 BLOCK。
- `aig-real3d-v119-wardrobe-lab.html` + UI：真正上傳原角色 PNG／GLB、各套獨立衣物 PNG／GLB，新增服裝與圖層，建立來源驗證衣櫃；按下拉選單立即以真 V99 來源場景的衣物網格 + PBR/來源材質進 V107 WebGL 切換。同一選擇還可在 A/B 上下翻轉、旋轉，並從腳至頭切片。真 callback，不是 CSS 換色或假按鈕。
- 原角色 GLB SHA、每個衣物 GLB SHA 與圖片 SHA、切換後場景 manifest SHA 分立；可下載 **JSON 衣櫃 manifest** 供後續使用，**不是聲稱已下載單一合併 GLB**，原始 GLB 需各自保存。
- 已提供真實來源 3D 與材質的服裝能改樣式；衣服**不會**憑空從同一張女主角照片預測出不同袖長/裙型。沒有布料垂墜、和角色皮膚碰撞、骨架蒙皮權重、自動貼身尺寸推估，也沒有實測真人真 1:1 的獨立認證。
- V118 本機神經網路仍存在並可從連結切回；但 V118 只會由標記的 RGB 訓練前景像素分類，並不會自動辨識衣物類型或生成經驗證的新衣物幾何。後續 AI 衣物理解應配授權資料集／權重、獨立遮罩基準及真正不同衣物 GLB 來源才放行。

## Gate
1. Node：兩套以上、不同衣物網格版型、每套多圖層，選取／回選確保角色原始幾何、SHA、頂點與材質不變，只有選中服裝送 GPU。重複 garment SHA、只有換色的假不同版型、假 V99 認證、錯誤 slot、未對位網格皆 BLOCK。
2. 真 Chromium：使用三組獨立來源 PNG 與由 V109 導出的真 GLB2 **合成測試資料**（1 角色 + 2 個形狀不同的服裝前表面），真 UI 上傳、V99 GLB SHA 解析、以 V107 真五軸 GPU 換兩套、截圖必須不同，原角色 SHA 與三角面恆定，A90/B120/75% 復原一致，回歸 V118 神經網路與 GLB。
3. 測試用衣服前表面是合成幾何，**不足以證明真 3D 布料厚度、物理碰撞、蒙皮動畫、真服裝裁片或人物照片 1:1**。實際效果需使用者提供或取得授權的服裝模型與角色模型、可驗證尺度及綁定結構。
4. V118 分支的 V111 獨立 Chromium regression 曾出現 30 秒逾時（來源標記預覽時），本階不更動 V111 判讀；相關項目未修復／未重測前不可宣稱 V111 regression PASS，也不能以新的衣櫃測試掩蓋來源測試失敗。
5. 本階是 GitHub Draft，**不** merge，不覆蓋正式 Render RGB HOME，不改 AIG-II／AIG Studio CNC/Fanuc，不更新 Android APK／Windows EXE。
