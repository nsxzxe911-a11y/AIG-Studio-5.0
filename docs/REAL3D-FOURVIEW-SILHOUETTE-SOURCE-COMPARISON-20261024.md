# Real3D｜四視角真人來源輪廓比對 Gate V1（2026-10-24）

## 本階目的
使用者要求：真正的咖啡色 3D 外形必須自然，不能再以假人、網格或炫光遮掩錯誤。本輪接續 PR #53 的本地 OBJ/GLB 匯入與來源審查，以及 PR #52 已通過 GPU 技術 Gate 的黑邊／咖啡色／柔和體積陰影。這一階並未獲得授權掃描人體基底；**重點是讓真正來源可被客觀核對，而非聲稱已自動重建人形**。

## 真實運作流程
1. 使用者匯入本機 OBJ/GLB、實測身高 mm、Y/Z-Up、可選解剖標記，保留檔案 SHA-256，不修改原始 XYZ。
2. 實際 WebGL GPU 渲染七張 1080 × 1920 PNG，其中用正面「咖啡平塗」、側/背/45°「咖啡體積陰影」各取一張相機固定的來源輪廓。
3. 使用者自行提供與上述正交相機、人體姿勢、解析度匹配的**透明背景 1080×1920 PNG 輪廓**。未去背普通照片一律拒絕；目前不宣稱自動人物摳圖或單張照片 1:1。
4. `aig-real3d-reference-silhouette.mjs` 在完全相同的像素坐標中計算 intersection/union、IoU、Dice、前景面積差。**不做 auto-fit／修腰／人物厚度變形／來源縮放**。
5. `aig-real3d-reference-silhouette-browser.mjs` 以真 ImageBitmap、Canvas 逐像素比對，輸出可下載實際差異 PNG 與各圖 SHA-256：咖啡色表示雙方重合、深褐代表只有參考輪廓、土黃代表只有 GPU 模型。
6. 只有四角參考都提供且真實比較完成，才回報「影像輪廓比對前置資料齊全」；即使 IoU 達 1.0，**仍然不表示真人真實性、五官結構、手指腳趾、照相 1:1 或電影視覺 PASS**。UI 與報告需維持 RELEASE BLOCK。

## 限制與不可造假的事項
- IoU 僅比像素佔據範圍；不判斷真實性或可識別身份，也不保證人物自然。
- 普通 RGB/JPEG 圖像完全不透明時**沒有可用輪廓 alpha mask**；必須先有可追溯的去背資料。工具本身沒有影像分割 AI，不能假裝自動去背成功。
- 不自動對齊四張參考照片的焦距、姿勢、擺位與拍攝尺度；輸入參考圖必須先與正交輸出規格對應，否則算出的是位移誤差而非人體比例誤差。
- 照片和真 OBJ/GLB 都只在瀏覽器解析；不呼叫遠端 AI，也不把來源圖送往 GitHub。
- GPU 測試用合成非人體網格及人工畫出的透明椭圓 PNG，是**純測試資源**；不能宣稱找到真實人體模型、真 AI 重建或比對真人通過。
- 停留在 Draft 分支，Render LIVE、已核准 RGB HOME、CNC 3~6AX/NC、手機/Windows APK/EXE 均不改動。使用者先核准的 AI 基礎渲染框架保留；微凹凸多次漸層陰影仍待後補。
