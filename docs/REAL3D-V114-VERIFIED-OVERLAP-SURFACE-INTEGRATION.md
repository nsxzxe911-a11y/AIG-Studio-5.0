# Real3D V114｜只整合來源已驗證的重疊三角面：保守去重與真 GPU Gate

第三專案 FastModel／Real3D。承接 V113 PR #115 已驗證雙視角深度和材質一致性。**不補不存在的背面、不用模板造假人、不把不同視角拉扯成閉合人體，也不改 CNC Fanuc 或 Render 正式入口。**

## 真實程式
- 新核心 `formal-web/shared-3d/aig-real3d-v114-verified-overlap-dedup.mjs`：讀取已由 V112 匯出的 GLB 原始二進位與兩視角真測量來源，先重跑 V113 正反雙向深度 Gate。若區域不一致、無實測重疊，立即 BLOCK。
- 對第二視角**現有**三角面的三個來源頂點逐點重新投影到第一視角：必須有可見對應像素、原始測量毫米深度差小於容許值、來源 PNG 原始 RGB 色差小於門檻才視為已重複。三個頂點均有來源佐證才在**新 GLB 工作副本的第二網格索引**中排除這個重複三角面。
- 第一視角完全保留，第二視角未可觀測、色差過大、深度不一致或邊界跨越的面保留；若沒有任何安全可排除的三角面就 BLOCK，絕不謊稱完成融合。
- **未更改**第二視角 POSITION/NORMAL/TEXCOORD_0 的原始數值或來源圖。輸出 GLB 新增索引緩衝與 accessor 計數修改；原始 BIN 完整 byte-for-byte 成為新 BIN 前綴，源貼圖、PBR 材質和來源模型 SHA 可逐一比對。新 GLB SHA 與原 SHA 必須不同。
- 新 GLB 工作副本仍是**兩組可見來源曲面**，不是 mesh 焊接、跨視角完整封閉網格或精度合格的真人 1:1。
- 繁中工作頁獨立 V114 核准勾選，預設仍用 V112 原始輸出；啟用時才將通過的工作副本交給 V99 GLB ingest，再由 V107 A/B 真 GPU 旋轉並下載，不動最原始來源。

## Gate 與真實限制
1. Node：V112 兩獨立深度來源 GLB → V113 真雙向重疊 Gate → V114 排除冗餘面，驗證第一網格數量不變、第二圖僅排除符合來源的索引、所有原 BIN 位元組保留、兩張原 PNG/材質與 XYZ/UV 保留。局部 9mm 深度異常、色彩完全不合或無重疊都 BLOCK。
2. 真 Chromium：以**合成的**兩視角平面量測資料與不同 SHA 原色 PNG，操作啟用 V114、真生成去重 GLB、V99 原載入／V107 A/B GPU／75% height，檢驗三角面數量減少但原 SHA 與新 SHA 分立；換成完全不同 RGB 來源或插入非 landmark 深度突起會 BLOCK；V113 原模式回歸不倒退。
3. 這不是檢驗真人掃描資料，合成測試不能宣稱光學掃描精度 0.001mm、人體結構真實度、真物理體積、完整背面或 1:1 照片相似度。輸出不可冒稱已獲獨立量測的密閉人體。
4. V113 Gate 過關 + V114 triangle dedup PASS 是技術子 Gate；**正式產品 Release Gate 仍 BLOCK**，至取得真實多視角掃描、真相機與深度證據、可見區域品質與缺面檢查都達標。
