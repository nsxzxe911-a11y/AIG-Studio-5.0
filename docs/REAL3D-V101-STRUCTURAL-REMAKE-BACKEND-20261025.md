# Real3D V101｜AI 重製與修整模型架構的後端繪圖核心

2026-10-25。承接 V100 的真本機 AI 推論執行器及 V99/V98/V96 來源/幾何/4K 核心。此階意圖把後端資料清理、幾何修復與 GPU 渲染**分開**：GPU 不是救得了所有壞掉的 AI 模型，先修模型，後渲染。

## 實際程式

- `formal-web/shared-3d/aig-real3d-v101-structure-repair.mjs`：從真正的 Indexed XYZ source mesh 偵測重複面、零面積退化面、開放邊、非流形邊、相鄰三角面的法線朝向衝突，以及原有連通島。經證據支援時，對相鄰面作一致方向修復，並在完整 Working Copy 中重算法線；可選擇明示允許刪除極少數零面積面，並保留原始 Face ID 映射。原始 GLB／來源三角面/XYZ 不可變。未經授權的穴洞不能補、失去的原臉與後背不能假造、零件島不能一鍵「清掉雜質」。
- `aig-real3d-v101-backend-orchestrator.mjs`：V100→V99 真 GLB 來源 → V101 診斷/結構修整 → 可選擇接入 V98 **真觀測**照片頂點誤差校正 → V96 4K Source Projection QA。神經網路生成權重如存在，仍由 V100 真 GPU Gate 單獨驗收；這一段幾何修復是可重現的確定性程式，不能冒稱已訓練 ML 代理。
- `formal-web/shared-3d/aig-real3d-v99-native-source-lab.html` 真繁中研究頁增加三個具真 callback 的控制：**V101 後端修整原始模型**、**查看原始模型**、**查看修整後模型**。真正以同一份 SH A鎖定 GLB 切換來源 Mesh／Working Mesh，原生 4K 輸出亦可依當前模式取像。報告保留各 Original Face ID、修正面索引、剩餘裂縫、非流形及零件連通資料。
- 通用 PERSON、ANIMAL、SHIP、ENVIRONMENT、CNC_PART。曲面拓樸清理與來源分件可以共用；人體骨架、衣服及飛船的結構語意，必須等待真正來源或可驗證 ML 輸出，不能因形狀相似自行斷言。

## 重要封鎖與意外修復防範

- 非流形模型：BLOCK，因為需要決定真實材料/零件連接關係，無法靠顯示器修補。
- 同幾何重複面：BLOCK，避免誤刪原機構表面或背對背薄殼。
- 零面積面：預設 BLOCK，只有明確批准且刪除比例足夠低時才可移除，且要求新增開放邊與連通惡化為零。
- 鏡像／正反面：只能確保共享邊的相對方向一致，**整個封閉模型朝內還是朝外**仍需材料／來源驗證。即使 orientation Gate PASS，也不代表已重現 AI 模型真臉。
- 高曲率修整、填洞、高密度幾何、頭髮拓樸、人體解剖與 PBR 材質都沒有在本階憑空生成。
- 修復後若幾何惡化或照片誤差未實際改善，必須 BLOCK；所有正式角色及 4K 電影發布 Gate 維持獨立。
- 本階 Source/GPU 測試使用多個故意反面的非人體四面體構成的真 GLB，不能冒充已修好正式女主角自然外型。

## 自動驗收

`aig-real3d-v101-structure-repair.test.mjs`：真正原三角面朝向衝突→修正、零面積來源拒絕/有許可才刪、非流形/重複面 BLOCK、多個有效部件不誤刪、來源 GLB 面及 SHA 不改，Source 單測。

`aig-real3d-v101-structure.real-browser.mjs`：產出實際 GLB 二進位輸入瀏覽器→載入 V99 真 GLB→V101 修復原面方向→切換原始／修整後模型→真正 3840×2160 GPU PNG SHA **應不同**，而來源 SHA/12 個原始測試面以及 3 個零件保持不變。提交原始與修復 PNG、SHA及工作階段報告。Source/GPU 必須同時 PASS 才能聲稱「V101 源網格修整技術原型通過」。不代表 AI 已輸出定版女主角電影級臉部。

## 下一個真正突破點

正式女主角更進一步的高品質自動重製，應把**已實際可用/已授權的本機視覺生成與深度模型輸出**注入 V101 修整路徑，將五官/頭髮/服裝/零件當成具備原始來源、可測量、可校驗的幾何，而不再以 3,784 面固定人體/補光/4K 等價於自然高擬真。該 ML 推論及女主角身份相似度仍需獨立 Gate。
