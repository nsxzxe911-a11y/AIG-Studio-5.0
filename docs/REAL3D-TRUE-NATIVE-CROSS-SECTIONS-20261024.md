# Real3D 下一階｜原始 OBJ/GLB 真三角面水平截面與左右分腿篩查（2026-10-24）

## 直接針對使用者指出的「正背面異常肥大」

PR #59／#60 的非人體合成橢圓網格在實際 GPU 檢查中，原始身高 1680 mm、最大正面寬約 839 mm、側面厚約 504 mm；改陰影、照相或修補缺失三角形無法把橢圓變成自然人。前版只有包圍盒尺寸，依然不能知道下半身是否有兩條真正分開的腿。

這次新增 `aig-real3d-native-body-cross-sections.mjs`：針對完整原始 **Indexed XYZ 三角面**，沿高度比例 **22%、37%、67%、94%** 做真正水平切面，逐三角形求世界坐標平面相交線段；把相同截面線段端點對接成連通環，實際量測各環的最寬 X、最厚 Z、交集線段、連通環／開鏈數量。量測不能改變任何三維頂點，也不新增假腿、網格、球體或 SDF。

- **下肢 22% 高度只有一個大型閉合截面**：標示 `ONE_LARGE_CLOSED_LOWER_BODY_SECTION_NOT_TWO_SEPARATE_LEGS`，即使原 OBJ 幾何、GPU 七視圖及 21 個假的測試標記形式上符合技術 Gate，也不得判成人體外形 ready。
- **原始 3D 網格在左右下肢高度確實產生兩個分離的閉合截面**：只給 `distinctSideBySideLowerLegSectionsObserved:true` 技術觀測，**不代表真人自然度、臉、五指、頭頸、模型來源、腳趾或單張照片 1:1 PASS**。
- 兩個以上區段不是兩條真腿的充分證據（連身衣、衣服內部網格、腿部姿態與不連通零件會影響）；切面碰到頂點平面產生歧義時明示警示，不能靜默證明天然人體。
- 同一算法可直接從本機 OBJ 解析的 raw triangles 處理，也可從 GLB 經既有共享 3D Scene／真正世界矩陣取得三角面切片，**不產生 GLB 不存在的後側資料**。
- 工作區新增四高度區段數值表，顯示實際來源切面連通環個數、閉合環個數、寬度 mm、實際交線數；原始模型與檔案 SHA 保留。
- 程序化單張照片 2.5D 明暗浮雕與 Stage1/SDF/Metaball 人體候選此前已明確不具自然真人外觀驗收資格，這次**不復活任何舊假人**，也不對人體輸出「胖／瘦」診斷。

## 驗證界線

Node 測試分別用明確非人體橢圓 OBJ（一個下肢封閉環）、完全不同的分離雙管 OBJ（真兩個環，仍非人體）、Y/Z-Up 與共享 Scene 測試；Chromium 使用原來的非人體 OBJ／GLB，驗證四個切面和「人體 ready BLOCK」的實際畫面。

GitHub PR 僅 Draft；不修改正式 Render 的 RGB HOME、CNC 3AX～6AX、NC、Windows EXE 或 Android APK。若日後能匯入經授權的完整人體三維來源，此幾何 Gate 才能配合四視角、21 個真正標記、真參考照片作自然度的獨立驗收。
