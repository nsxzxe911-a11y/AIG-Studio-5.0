# Real3D｜真雙通道三維動作影格與三角面穿插診斷 V1

2026-10-24。接續 Draft PR #70 的原始 OBJ 顯式權重單關節真頂點變形工作副本；依序基於 #69、#68、#67、#66。禁止引入 SDF／Metaball／Template Morph／Subdivision 來捏出假人體。

## 真正增加的能力

一份來源檔 SHA 配兩組分別屬於不同手指的本機頂點權重 JSON（前階既有 JSON ＋本階第二組）；兩組都需要被來源索引、身高、原始關節 Middle 標記驗證。每個通道用上一階**真 Rodrigues 頂點旋轉**。兩個控制區的權重不能覆蓋同一個 source vertex，否則 BLOCK；這一階不是層級 Rig，不允許把兩組獨立通道當父子骨架。兩個關節各有目標角度，介面預設 +20°/-20°，範圍 ±45°。

每個真時間取樣影格計算兩組原始 XYZ 姿態（0%/50%/100%），輸出新 Float32Array，原始 Uint32 GLOBAL face index／OBJ 始終不變。Node 庫可配置 3–9 個采樣幀，瀏覽器 V1 使用三幀真 GPU 1080×1920 PNG + 各自 SHA；**不是兩張圖片交替的假 animation 也不聲稱完整 60 FPS/MP4**。

每一幀：
- 對來源原始三角面檢查變形比例、最大邊拉伸/壓縮百分比、變形三角面數、翻面和塌陷；
- 從 source-index 取得兩組受控頂點有接觸的所有原始三角面；原始 adjacency 共頂點面跳過；對跨組三角面先做 3D AABB broadphase，再做雙向線段－三角面窄階段相交測試（非共面）；可量測確實穿插的三角面對；
- 以每幀最多 150,000 narrowphase 配對（上限最多 200,000）與 16 倍 broadphase 候選檢查上限防卡頓；如檢查耗盡，明確回報 budgetExhausted，絕不宣稱安全；
- 沒檢出碰撞僅表示**有限影格、有限區域、非共面交叉**沒有看到，無法推論取樣間時刻／整體與全身／共面接觸／所有人體自碰撞都安全。

## 真正不做的事情

此階段是兩個相互獨立的顯式權重通道，不是真實人體多節指骨的 parent-child FK，也沒有皮膚應力物理學、指甲/血管/真實接觸或源頭真人 1:1 認證。任何標記/權重缺少、假 SHA、無原來源就 BLOCK。技術成功後真人外觀、Rig、真 60 FPS 連續動畫、APK/EXE/正式發版繼續 BLOCK。

## QA

Node 以明確非人體原始立方體驗證五個時序影格、兩個真正不同的來源通道、真頂點改變但來源不可變、無重疊權重；獨立的三角面交叉 fixture 實測**真的 3D 非共面相交**，移開後不相交，候選超出 budget 也必須 BLOCK。

Chromium 繼續使用 113,400 原始頂點、226,080 三角面 NONHUMAN OBJ 回歸，兩個正確來源 SHA 與互不相交的 sparse weight manifest，檢查三幀均是真 GPU／有不同姿勢／原面數保留，下載 1080×1920 PNG 和 JSON SHA 一致。
