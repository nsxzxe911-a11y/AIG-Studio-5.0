# AIG FastModel Real3D V118｜真正的本機學習型像素神經網路與五軸 GPU

第三專案 FastModel／Real3D，延續 V117 PR #119；本輪由純規則式來源判斷前進到**真的神經網路參數訓練與推論**，但沒有已訓練的人體語義辨識模型，也沒有宣稱單張照片能 1:1 重建完整人體。只在 GitHub Draft 研究分支施工，正式 AIG Render HOME 不改、不動 CNC/Fanuc/Android APK/Windows EXE。

## 真的 AI 在哪裡
- `aig-real3d-v118-local-neural.mjs` 是獨立、完全本機的 3 個 RGB 輸入 → 12 個 tanh 隱藏神經元 → 1 個 sigmoid 輸出的 **61 個可學習參數神經網路**。訓練從本張照片上使用者真正標記的至少 2 個前景和 2 個背景像素開始，完整執行 Adam 梯度下降 900 輪，輸出實際浮點權重 SHA-256、訓練損失和逐像素推論機率。不是只用 threshold 冒充深度學習，也無網路/CDN/第三方雲端模型。
- 需要使用者給前景/背景色樣本。它學會的是**此張照片 RGB 顏色差異**，不是有真實人類／動物／臉／衣服／頭髮的先驗知識；不能冒充 pretrained semantic segmentation、不可以宣稱「任意複雜背景零標記 100% 全自動」。
- 強制 foreground/background 種子分離、訓練分類信心、覆蓋率、不可碰框、單一連通、未確定像素預算；失敗就 BLOCK。原照片 RGB/原始 PNG SHA 完全不更改，只創建獨立 alpha PNG 工作副本，模型權重 SHA 和新 GLB SHA 均保留。
- 對 V111 共用的原圖紅／藍點標記 UI 增設「V118 本機神經網路」選項，**禁止與 V111 傳統色差模式或外部遮罩同時啟用**；有真「訓練並預覽」按鈕，權重 SHA、樣本數及訓練 loss 都會顯示；若不選 V118，原 V109/V110/V111/V117 不回退。
- V118 選中後，V117「自主分析／自主執行」真正訓練模型，根據學習結果產生 alpha 工作副本 → V109 indexed GLB 真材質 → V99 來源 GLB parser → V107 五軸 WebGL 真繪製 A0/B0、A90/B0、A0/B90、A90/B90、A45/B180 與 50% 高度切片。自動執行前重新訓練並確認 **模型權重 SHA、前景像素數、來源圖片 SHA、獨立深度來源 SHA** 一致，防止中途更換檔案或標記。
- 此項「神經網路實際執行」可以 PASS，但這只是自行訓練的小型 RGB 分類器；未經真實人物資料集獨立測試，不得視為人物外形擬真或照片 1:1 PASS。
