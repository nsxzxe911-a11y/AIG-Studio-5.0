# Real3D V1｜非平面來源曲面接合工作副本（2026-10-24）

## 核心原則

承接 PR #64 的五區原始三角面解析度測量、PR #63 的真 2K／4K 螢幕解析度、PR #62 的**僅平面小破洞**工作副本。這次是真正原始 OBJ 非平面小範圍插值，**不是**生成可信真人身體、手掌五指、腳趾或頭臉。

### 受控適用範圍

- 原始 OBJ，提供 SHA、mm 實際校正與 Y／Z Up。只能由本機工作區使用者按真按鈕建立**新工作副本**，不得改動原始檔。
- 只能處理來源真 Indexed 三角面界定的**唯一 4～8 邊閉合凸形缺口**，直徑不超過 90 mm，邊界相對平面真正非共平面（偏差 ≥0.01 mm）但不超過 3 mm。
- 原來源不得有退化三角面、非流形、面片繞向不一致或分叉／多個缺口；這些有缺陷的情況一律 BLOCK，不偷焊接、不把正常面刪除後重建。
- 利用原始洞緣 3D XYZ、鄰接三角面法線與對應三角面第三頂點推估近似中心；**曲率校正沿法線絕對值 ≤1.5 mm**。以原來源所有頂點、原來所有面片**完整保留**方式追加一個來源新頂點與 4～8 個真面片，面片最小面積、相鄰原始面片角度不超過 55°。
- 修補候選另讀回原真 OBJ 匯入器，必須 openEdges、nonManifoldEdges、degenerateTriangles 全 0、頂點及面片數量剛好符合新增量，才可下載。
- 匯出工作副本各自計算 SHA，可在同一工作區經原來的四個 GPU 正交相機、五個局部區域與前後 OBJ 差異報告進行獨立檢查。

## 特別不能做的事

來源未實際拍到的曲面深度，不能由這種小型插值恢復真值。這個修補結果是**近似候選**，幾何開放邊消失也不是曲面自然度通過。不能在頭頸大範圍缺損、手掌缺少手指、嚴重衣服貼圖錯誤或頭髮遮擋處執行無證據的補面；不啟用 SDF/Metaball/Template Morph 重新做「橡膠假人」。

因此報告永久保留 `newSourceGeometryIsInterpolatedApproximationNotMeasured:true`、`realHumanShapePASS:false`、`releasePASS:false`。

## Gate

Node 使用明確**非人體**來源 OBJ，真刪去同一網格上相鄰兩片三角形，並更動來源其中一個局部頂點使四邊缺口真的非平面，證明新 vertex、三角面及來源保留。來源恰好平面、太大、高曲率、無權限、來源不合格等均 BLOCK。

Chromium 使用真 WebGL，從異常非人體 OBJ 檢查頁點擊真按鈕建立獨立 OBJ，核對下載檔 SHA、原本頂點／面片未被改動，並導入真四視角 GPU 比較。請勿把這個技術 Gate 當成真人外觀驗收。
