# Real3D V1｜原始 OBJ 局部接合與缺面品質 Gate（2026-10-24）

## 本輪交付：從「標記位置」進入「實體網格品質」

承接 PR #56 的 OBJ 21 點原生座標→四視角真 GPU 畫面，以及 PR #55 的像素寬窄誤差。**只有原始 OBJ 和經網格貼合審核的來源標記**才能啟用新的局部接合檢查。

本次工具分析的是真實來源 Indexed XYZ 三角面而不是二維圖片：在五個由標記 XYZ 定義的局部鄰域，尋找開放邊、非流形邊、面片纏繞方向衝突、來源標記落在不相連幾何分量及標記離原始表面過遠。輸出包含局部異常邊位置的原始世界座標示例，可供後續 CAD/建模工具人工查修，但**本版絕不填洞、焊接、平滑或新增三角面**。

| 原始標記限定的區域 | 使用的來源標記 |
|---|---|
| 頭頸附近 | 下巴、頸根、左右肩 |
| 左手附近 | 左手腕、左拇指尖、左食指尖 |
| 右手附近 | 右手腕、右拇指尖、右食指尖 |

**注意**：表中左右手只有拇指與食指兩個供對應的來源標記。資料不包含五根手指各自的充分拓樸資訊，故即使全部技術檢查「沒有異常」，**仍不能推出五指/足趾完整、真人頭臉自然、頭頸無視覺接合缺陷或照片一比一**。技術 Gate 與真實人體外觀 Gate 分離。

## 技術邊界與有效性

- 使用與既有 OBJ importer 相同的 Y/Z-Up、身高校正、原始三角形索引及已審核標記，來源檔 SHA 保存。對每個區域設定可解釋的實際半徑（約量測身高的 5%，下限 40 mm）尋找原始頂點與邊；**不是人體真實皮膚分區**。
- **OpenEdges** 是三角面索引只使用某邊一次；**NonManifold** 是同一邊由超過兩面共用；**WindingConflicts** 是相鄰兩個面對共有邊沿相同方向使用。這些都是原始拓樸診斷值，非 AI 生成影像。
- **DisconnectedIndices** 比較標記最近頂點所在索引連通元件；即使相鄰頂點位置接近也不將它們擅自焊接。標記最遠貼合誤差保留 mm 數值及疑點。
- **只檢查局部鄰域**，異常若遠離所有標記，不一定會在本輪局部表格列出，因此總體幾何 Gate 仍獨立保留；全部 local checks clear 不可取代全球審核。
- 不確定資料（來源無 OBJ/GLB 原生對應、21 點缺漏或原生標記 Gate 未通過）顯示 BLOCK；仍可使用原本咖啡色 GPU 視角、沒有來源部位判斷的 12 分段像素表。
- 檔案與模型全在使用者瀏覽器讀取，不遠端上傳個人照片/人體資料。不改 RGB HOME、Render LIVE 或 CNC 3AX～6AX/NC。
- SDF、Metaball、Template Morph、Subdivision 重建人體候選仍淘汰。五指、足趾、臉部、外觀比對、動畫骨架、電影完成度維持 BLOCK。

## 測試內容與失敗條件

- 明確 **NONHUMAN 合成封閉 OBJ**：確認五個局部拓樸檢查區域、真頂點參照、近表面距離、原始 SHA、沒有修改來源以及無自動真人 PASS。
- 在合成 OBJ **頭頸附近真挖掉一片原始三角形**：必須在頭頸附近檢測到開放邊，並提供異常邊 XYZ 座標。
- 在同位置**翻轉一個原始三角形的索引繞向**：必須檢測到共邊方向不一致。
- 來源 SHA、標記、實測身高不合法或標記距離原網格太遠，分別 BLOCK 或報出問題；不得以單一對齊漂亮的 GPU 圖給 PASS。
- Chromium 原 7 張咖啡色 GPU 截圖、4 張來源標記疊圖、4 張參考誤差圖與 JSON 仍回歸，新增頁面五列「真三角面鄰域」量測。

以上是技術診斷的新能力，不代表已有可信真人掃描素材。本 PR 保持 Draft，未經整合 Gate 不得部署正式 Render 或宣告 APK/EXE 成品。
