手機與電腦，同一份專案格式

此頁可把目前瀏覽器已儲存的 CAD、CAM、工件、刀具、工作座標及 3～6AX G-code 打包成檔案，再在另一台裝置的 AIG-II 網站匯入。所有動作都在本機執行。

本機保護備份

匯入前，會先保留受到變更的原資料。可在此選取先前的備份還原；還原也會先建立反向備份。

本機備份會隨瀏覽器網站資料被清除而消失。若要長期保存，請另外下載專案檔。

跨裝置操作

  1. 裝置 A：在工作區儲存 CAD、CAM 或 NC，再按「匯出 JSON」。
  2. 透過自己的檔案、隨身碟或 Google Drive 手動傳輸 JSON。
  3. 裝置 B：在同一個 AIG-II 網站開啟此頁，選擇檔案。
  4. 確認 SHA-256、衝突欄位，選擇保留本機或採用匯入版，然後套用。
  5. 重新開啟 CNC 工作頁以載入更新的資料。
