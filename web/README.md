# AIG Studio 5.0 Web Runtime Preview

目前主程式網頁鏡像：`web/main-runtime-preview.html`

- AIG Studio 370.0.0 主 Runtime 與 Main Runtime Web Preview 使用同一份 WebGL 頁面。
- HOME / CAD / CAM / SIM / 3AX / 4AX / 5AX / 6AX / NC。
- RGB Glass、Neon、Dark Ice 可即時切換並保存選擇。
- 3AX～6AX SIM 使用 WebGL 工件、支撐座及可旋轉刀頭模型。
- 離線：直接使用目前安裝版本與設定。
- 線上：HOME FIRST，讀取條與說明顯示版本比對流程，只接受 verified newer。
- Regression：OFF / LOCKED。
- CNC 真機輸出：Web Preview 停用。

`web/main-runtime-preview.html` 與 `web/index.html` 保持位元內容一致。

> Web Preview 是實際 WebGL Runtime 預覽，不是 APK/EXE 實機啟動證據。
