AIG-II / HELP CENTER

常見問題

網站首頁用來瀏覽技術內容和選擇工作頁；正式 CNC 編輯與模擬功能放在獨立工作區，不會在公開首頁出現工程控制殼。

網站與操作入口

首頁和 CNC 工作區有什麼差別？

首頁用來查看功能分類、教學與更新資訊；點選 工作區 後，才進入 CAD、CAM、SIM、3～6AX、NC 或 AI。網站改版不會自動代表所有加工核心已完成驗收。

我已經有 G-code，可以直接開始嗎？

可以從 NC 編輯頁 開始，不必先建立 CAD 草圖。請先核對控制器與機台支援的指令，再解析、模擬、單節和空跑檢查；不要把網頁中的預覽當作真機加工許可。

搜尋欄和分類按鈕怎麼用？

回到 功能分類，可選擇 CAD/CAM/SIM、3～6AX 或 NC/AI，再輸入關鍵字搜尋功能。按 Ctrl+K（Mac 為 Command+K）可快速把游標移到首頁搜尋欄。

「最近使用」會同步到其他裝置嗎？

不會。網站的「最近使用」入口只保存在目前瀏覽器的本機儲存空間，清除網站資料、無痕模式或更換裝置後可能消失。它不是 CNC 專案同步，也不會保存 G-code 內容。

離線、版本與視覺

網路中斷還能開網站嗎？

成功載入並快取過的網站頁面與部分工作區資源可供離線使用；第一次開站、快取遭清除或某項資源未保存時仍可能需要網路。請先在有網路時開啟所需頁面並確認功能正常。

為什麼我還看到舊網站畫面？

可能是瀏覽器分頁仍載入舊版本，或網站快取尚未更新。請先重新整理頁面；若仍舊版，可關閉舊分頁後重新開啟 正式首頁，並檢查瀏覽器中的網站快取。重新整理前請先儲存未完成的 CNC 編輯資料。

RGB 風格是否代表全部都是原生 4K？

不是。網站的 RGB 玻璃樣式與桌面／手機各頁的原生 4K Authority 圖是不同驗收項目。外觀更新不會自動證明每張素材已達 3840×2160，也不等於 CNC 模擬和材料移除功能已完成。

加工安全與檔案

可以直接讓網站控制真實 CNC 機台嗎？

目前網站工作區的實機輸出保持停用。即使有 G-code 編輯與模擬，也需要機台連線、控制器支援、安全互鎖、程式核對及實機驗證，才可考慮真機輸出。

到哪裡確認可下載的 APK 或 EXE？

查看 AIG-II GitHub Releases；務必核對發佈版本、附件、SHA 與驗收證據。網站的 GitHub 更新紀錄不應被當成 APK／EXE 已通過的證明。

Fanuc、旋轉軸、刀長補償及自訂 M-code 均可能依機台型號和參數不同而異。實機加工前應依現場程序獨立驗證。
